# Scale-v5 original failure and intervention-input review

**Gate: passed.** This audit covers the frozen original phase before any intervention outcomes are examined.

The audit reads only the original candidate file, original request ledger, original-only cache entries named by that ledger, frozen source packs and their saved audit rows, and original-phase protocol/selection files. It does not enumerate or open intervention caches or outputs. It makes no model calls and writes only these two review files.

The committed continuation amendment permits one terminal capacity failure to remain as an original row with no answer. The audit checks its exact request/cache identity, confirms the old 696-key cache prefix is unchanged, and keeps the transport failure out of value-failure accrual.

It rechecks 1120 saved answers against their visible source text and independently recomputed source audits. It verifies the frozen accrual stopping rule, seeded ranking over every accrued usable schema-valid value failure, and separation of the 96-case audit. It also constructs prospective fresh and repair request identities in memory. For each selected case the inputs are identical; fresh has no feedback, and repair contains only the exact sample-0 answer and generic verifier flags. Full prompt bodies are not saved here.

The prospective plan has 600 paired cases, 600 fresh requests, 600 repair requests, and 300 complete four-request waves.
