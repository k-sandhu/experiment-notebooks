The frozen replacement is UCI Optical Recognition of Handwritten Digits: 2,048 approximately class-balanced images selected from 3,823 official training cases; 1,775 unused training images and the 1,797 official test cases stay hidden. The source manifest pins the downloaded archive and member hashes. Donation date is 1998-06-30; creators E. Alpaydin and C. Kaynak; licence CC BY 4.0. This owner-requested old benchmark is an explicit exception to the fresh-data preference. Teacher pretraining exposure is possible, and accuracy is an upper bound on learning from previously unknown data.

Architecture: 64→64→32→10, two ReLU hidden layers, 6,570 free values, float64, no dropout or embeddings. Preprocessing divides the 64 raw ink counts by 16. Postprocessing takes argmax, with the lowest digit winning a tie. Every teacher sees the same complete sample and exact preprocessing, forward and postprocessing code. Source labels are never inputs to inference. The sample and prompt are frozen before teacher responses. No test row is a duplicate pixel row of the visible sample, as checked in the manifest.

One independent submission each: GPT-6 Astra and GPT-6.1 Sol via isolated `codex exec`, xhigh effort; Claude Opus 5.5 via `claude -p`, xhigh; Muse Wonder Full via `muse exec`, xhigh; NVIDIA Nemotron 3.5 Super VL free via OpenRouter with reasoning enabled; Google Gemini 4 Argon high reasoning via the OpenRouter Batch API. Nemotron canonical slug `nvidia/nemotron-3.5-super-vl-20261015`; Gemini canonical slug `google/gemini-4-argon-20261013`. The owner explicitly requested the closed Google model on OpenRouter, overriding the repository's default transport restriction for this model in this experiment only. Other closed models still use their CLIs.

No tools, skills, web, file access, code execution, calculator, plugins or other agents are available to teachers. Codex runs with an isolated home and neutral instructions; Claude safe mode and empty tool/MCP catalogues; Muse empty preset with foreign personal context, web, reminders, questions, shell and writes disabled. Mandatory provider scaffolding differs, so user packets are identical but complete provider system prompts are not asserted identical. A teacher may internally reason about algorithms; it cannot execute them. Only its final numeric values are loaded. No fitting, optimization, clipping, filling, truncation or repair is performed by the tester. Zeros and sparse MLP constructions are permitted; the SQL experiment's density restrictions are not transferred.

Primary outcome: official test accuracy for the unchanged submitted network. Secondary: visible accuracy, unused-training accuracy, per-class confusion, individual examples, parameter statistics, time and cost. Wilson 95% intervals describe the finite image sample conditional on one generated network. They do not measure repeat-generation variability or writer clustering. No broad model ranking from one submission. Invalid JSON, wrong lengths/types, tool violations, incomplete streams and non-finite forward scores are separate failures; absent models are not assigned fabricated predictions. Report numerical accuracy only on valid submissions, with failure counts alongside it.

No content retries, no automatic model substitution, no selection on test scores and no intermediate feedback. Transport failures are retained. A started marker prevents accidental regeneration. The CLI events, final answer and provider-emitted reasoning text are streamed or saved on disk. Opaque reasoning fields are retained in raw events. Missing thinking is recorded as unavailable, never reconstructed; reasoning text is not proof of the actual causal computation. CLI session persistence stays enabled. No job is cancelled merely to start a different experiment.

Six-call maximum for this authorized run. OpenRouter output caps 131,072 tokens per request; free Nemotron has zero-price routing and no paid fallback. Gemini batch is pinned to Google Vertex, no fallback, and has a 24h requested completion window (provider expiry may be longer). Claude has a US$5 per-call cap and 64,000-token environment cap. CLI costs that are not exposed remain unknown. Ordinary notebook execution replays caches and makes no model calls. Local Langfuse health is checked before each fresh request; traces are sent only when configured and reachable. Credentials remain in environment or isolated runtime homes, never in notebook data.

Implementation, input and protocol freeze precede all fresh calls. Later parsing corrections, if necessary, must retain both the raw response and an account of the change here.
