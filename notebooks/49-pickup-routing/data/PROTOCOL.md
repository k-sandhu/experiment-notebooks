### Scoring fixed before pilot

Score a plan as dispatchable only when all currently required pickups appear exactly once, planned departure and depot return fit the vehicle's shift, the right truck serves each load, each pickup finishes by its closing time, and cumulative weight, cube and pallet count never exceed capacity. Return to the common depot is implicit. Enforce directional, vehicle-profile road times. Unreachable legs violate the plan.
