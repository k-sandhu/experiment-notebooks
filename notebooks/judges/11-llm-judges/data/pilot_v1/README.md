# Original notebook 11 pilot

This folder preserves the first study, including its executed notebook, original README, input data, cached
responses, result tables and figures. Both judges matched all 96 gold ratings on 12 pairs built from four
underlying scenarios.

- Read the [original explanation](README_original.md).
- Open the [original notebook with its outputs](11_llm_judges_original.ipynb).
- Read the [extended study](../../README.md) for the new experiments and a discussion of the pilot's limits.

The original README refers to its former notebook filename. The archived file is named
`11_llm_judges_original.ipynb`. Copy this folder elsewhere before rerunning it so the preserved outputs remain
unchanged. Its input paths are relative to this folder and its default execution replays the original cache.

The extended notebook checks the original evidence against `preserved_files.json`. It does not recollect or
overwrite the pilot's results.
