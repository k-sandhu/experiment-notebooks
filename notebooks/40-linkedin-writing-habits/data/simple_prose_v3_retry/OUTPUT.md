# Retry of the empty SETI generation

The Allen Telescope Array processes up to 2.4 terabits of sensor data per second, with AI inference running beside the instrument. That setup lets agents work on observations as they arrive, while keeping the data on site.

Breakthrough Listen and the SETI Institute are connecting that live stream to agents that can steer antennas, calibrate the telescope and correct data errors. Researchers can issue instructions in natural language through Nexus, an observatory system that tracks the instrument’s state, computing resources and processing pipelines. The agent can act using current information about the equipment it controls.

The pipeline has already detected a pulsar in the Crab Nebula in real time. That is a concrete result involving a known type of astronomical source as the team develops the system for the search for extraterrestrial signals.

The team is also evaluating open models, including NVIDIA Nemotron, for settings where local processing and response time matter. Those evaluations could inform future observatories designed to operate offline, including instruments that may someday sit on the far side of the moon.
